API — перепустка для програми

API-ключ складається з Key і Secret. Він дозволяє програмі звертатися до вашого біржового акаунту з визначеними правами. Пароль Binance для цього StrIM не потрібен.

Читання дозволяє отримувати дані. Спотова торгівля — купувати й продавати активи. Withdrawals — виведення. Для StrIM залишайте останній дозвіл вимкненим.

Створіть окремий ключ

  1. У Binance відкрийте API Management і створіть системно згенерований ключ для StrIM.
  2. Пройдіть перевірки безпеки, які запропонує біржа.
  3. Увімкніть Reading і дозвіл на спотову торгівлю. Назва торгового дозволу може містити Spot & Margin Trading.
  4. Залиште Withdrawals вимкненим. Додайте актуальний IP з блоку «Binance API» у кабінеті StrIM до дозволених адрес.
  5. Збережіть обидві частини ключа у власному кабінеті StrIM. Secret не публікуйте й не надсилайте підтримці.

Що перевірити після збереження

Напис «З’єднання з біржею OK» означає, що StrIM може отримати дані акаунту. Це ще не підтвердження торгової операції. Окремо перевірте дозволи, вільні USDT на споті, параметри стратегії й журнал після запуску.

На телефоні блок Binance API доступний у вкладці «Торгівля». Відео й докладні кроки є в інструкції з підключення.

Якщо ключ став відомий стороннім

Відкличте його в Binance, перевірте акаунт і ордери. Відкликання ключа не продає монети й не означає автоматичного скасування всіх ордерів. Створіть новий ключ після перевірки захисту акаунту.

Вимкнений дозвіл на виведення зменшує можливості цього ключа, але не усуває ризик збиткових угод. Докладніше — безпека StrIM.

Торгівля може принести збитки. Прибуток і строк закриття позиції не гарантовані. Приклади пояснюють механіку, а не прогнозують результат.
