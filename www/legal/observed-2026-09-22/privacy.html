Політика конфіденційності

Власник і оператор сервісу StrIM: ТОВ «СтрІМ Алго», код ЄДРПОУ 46241790. Редакція: 1.0, діє з 09.05.2026.

1. Які дані можуть оброблятися

  • ідентифікатор облікового запису, електронна пошта, ім’я/нік (якщо вказані);
  • дані сесії (технічні маркери, IP-адреса, user-agent) — для безпеки та запобігання зловживанням;
  • ключі API біржі та пов’язані технічні параметри — лише в обсязі, необхідному для роботи інструменту;
  • ідентифікатор чату Telegram / технічні повідомлення — якщо Користувач підключив сповіщення;
  • облікові та журнальні записи про дії в Сервісі (логи подій у межах платформи).

2. Мета обробки

Надання доступу до Сервісу, автентифікація, підтримка, виконання договору (оферти), безпека, дотримання законодавства, зокрема щодо протидії зловживанням.

3. Зберігання ключів API

Ключі API надаються Користувачем добровільно. Виконавець застосовує технічні заходи захисту (зокрема шифрування при збереженні в базі даних) і не використовує ключі на інші цілі, ніж робота обраного функціоналу Сервісу відповідно до оферти. Пароль від акаунта біржі Виконавець не отримує і не зберігає.

4. Передача третім особам

Дані не продаються. Передача можлива лише: хостинг/інфраструктура для роботи сайту; поштові та технічні сервіси; за вмотивованою вимогою державних органів у випадках, передбачених законом.

5. Строк зберігання

Дані зберігаються протягом дії облікового запису та строку, необхідного для виконання зобов’язань і захисту прав сторін, якщо інше не встановлено законом.

6. Права Користувача

Користувач може звернутися з запитом щодо доступу, уточнення, обмеження обробки або видалення даних (з урахуванням технічної можливості та вимог закону) через контакти, зазначені в оферті.

7. Зміни політики

Виконавець може оновлювати цю Політику; актуальна версія розміщується за цією адресою. Продовження використання Сервісу після публікації змін означає ознайомлення з оновленням, якщо інше прямо не вимагається законом.
