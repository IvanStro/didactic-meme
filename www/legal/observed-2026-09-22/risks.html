Розкриття ризиків

Підключення до сервісу StrIM (ТОВ «СтрІМ Алго») передбачає усвідомлення наведених нижче ризиків. Текст є інформаційним і доповнює публічну оферту.

Користувач розуміє, що торгівля криптоактивами та використання API бірж пов’язані з ризиком повної втрати коштів. Сервіс не гарантує прибутку і не є інвестиційною порадою.

1. Ринкові та біржові ризики

  • волатильність цін, ліквідність, зміни правил біржі, блокування акаунта біржею;
  • затримки виконання ордерів, технічні збої біржі, форс-мажор;
  • зміни комісій і лімітів біржі без попередження з боку третіх осіб.

2. Ризики API та автоматизації

  • компрометація ключів API, помилкові налаштування прав доступу;
  • розбіжність між очікуванням Користувача та фактичною поведінкою стратегії або затримками синхронізації;
  • обмеження доступності Сервісу (техроботи, збої хостингу, мережі Інтернет) без гарантованого SLA.

3. Юридичні та регуляторні ризики

Законодавство щодо криптоактивів та фінансових послуг може змінюватися. Користувач самостійно оцінює правомірність використання Сервісу у своїй юрисдикції.

5. Відповідальність користувача

Користувач самостійно обирає торгові пари, розмір депозиту, параметри стратегії та перевіряє налаштування API на Binance. Перед запуском рекомендуємо ознайомитись з інструкцією, FAQ та тарифами.

6. Підтримка та звернення

Якщо ви помітили технічну аномалію в кабінеті або підозрюєте несанкціонований доступ до API — негайно зверніться на support@strim.in.ua і відкличте ключі на Binance.
