Підключення через API дозволяє StrIM виконувати спотові угоди. Нижче — що саме ви дозволяєте і як контролювати доступ.

Схема дозволів, не скриншот Binance. API без виведення все одно може виконувати збиткові покупки й продажі.

01

Окремий ключ

Створіть API-ключ лише для StrIM. Пароль Binance, коди входу й резервні ключі автентифікатора сервісу не потрібні.

02

Обмеження IP

Додайте актуальний IP із блоку «Binance API» у кабінеті до дозволених адрес на Binance. Звіряйте його перед зміною ключів.

03

Особистий кабінет

API Key і Secret вводьте у власному кабінеті на strim.in.ua. Не надсилайте їх у листування та не показуйте на скриншотах.

Що означає «З’єднання OK»

StrIM зміг отримати дані біржового акаунту. Це не підтвердження виконання угоди й не заміна перевірки торгових дозволів. Після запуску перевірте журнал.

Як зберігаються ключі

Сервіс зберігає ключі в зашифрованому вигляді. Шифрування є одним із заходів захисту; воно не робить будь-яку систему невразливою. Ви також контролюєте дозволи ключа та можете відкликати його на Binance.

ЯКЩО КЛЮЧ МІГ ПОТРАПИТИ ДО СТОРОННІХ

Спочатку закрийте доступ.

  1. Відкличте підозрілий API-ключ у Binance.
  2. Перевірте біржові ордери, позиції та історію операцій. Відкликання ключа саме по собі не продає монети й не скасовує всі вже створені ордери.
  3. Захистіть акаунт Binance й створіть новий ключ із потрібними дозволами.
  4. Зверніться до підтримки StrIM з описом ситуації. Секретний ключ до звернення не додавайте.
API — перепустка з дозволами. Ключ від усього будинку боту не потрібен.
