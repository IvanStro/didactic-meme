# Скріни кабінету для головної

Файли на головній (`#product-preview`):

| Файл | Що на скріні |
|------|----------------|
| `cabinet-overview.webp` | Огляд кабінету (портфель, статуси, журнал) |
| `cabinet-strategy.webp` | Рівні сітки, старт/пауза |
| `cabinet-chart.webp` | Графік пари: рівні, покупки/продажі |

Не публікувати скріни з модалкою підтримки, відкритими новинами чи нікнеймом у шапці.

Покладіть сюди три файли **WebP** (без API-ключів, email, реальних сум — можна blur):

| Файл | Що на скріні |
|------|----------------|
| `cabinet-overview.webp` | Огляд: портфель, список пар/статусів |
| `cabinet-strategy.webp` | Обрана пара: рівні сітки |
| `cabinet-journal.webp` | Журнал угод |

Рекомендовано: ширина 1200–1600 px, темна тема як на проді.
