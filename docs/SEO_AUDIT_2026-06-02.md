## 1. Технічне SEO

| Перевірка | Статус | Деталі |
|-----------|--------|--------|
| HTTPS + HSTS preload | ✅ | `Strict-Transport-Security` на apex |
| www → non-www | ✅ | 301 у `.htaccess` |
| `robots.txt` | ✅ | Закрито `/api/`, `/admin/`, кабінет, forgot/reset |
| `sitemap.xml` | ✅ | 12 публічних URL + `lastmod` |
| Canonical URL | ✅ | На всіх індексованих сторінках |
| Службові сторінки | ✅ | `dashboard`, `strategy`, `pair_details` — `noindex` |
| Favicon / manifest | ✅ | favicon.ico, apple-touch-icon, webmanifest |
| Стиснення | ✅ | mod_deflate для HTML/CSS/JS |
| Analytics | ✅ | gtag + Consent Mode v2 |

**Рекомендації (технічні):**
- У Search Console додати **обидва** властивості: `strim.in.ua` і `www.strim.in.ua`, вказати бажаний домен **без www**.
- Після деплою: **Sitemaps → надіслати** `https://strim.in.ua/sitemap.xml` → **Запросити індексацію** для `/`, `/tariffs.html`, `/faq.html`.

**Що було виправлено в репо (02.06.2026):**
- Скорочено title головної (було ~97 символів).

## 4. Контент і ключові запити

| Кластер | Приклади | Сторінка-носій |
|---------|----------|----------------|
| Бренд | strim, стрім алго | Головна |
| Binance spot бот | бот binance spot, автоматизація спот | Головна, FAQ, інструкція |
| Ціна | strim ціна, 500 грн | tariffs.html |
| API | binance api бот | instruction.html |
| Довіра | оферта, ризики, aml | legal pages |

**Сильні сторони:**
- Чітке позиціонування: **не провайдер інтернету**, а **SaaS + Binance spot**.
- FAQ з schema.org — rich results у Google.
- ЄДРПОУ, ТОВ «СтрІМ Алго» на головній (E-E-A-T).

**Слабкі сторони (контент):**
- Немає розділу `/blog/` — втрачаємо long-tail («сітка на споті binance», «strim vs royalq»).
- Мало зовнішніх посилань (off-page) — окремий маркетинг.
