# Багатомовність StrIM (справжні переклади)

## Принцип

- **Українська (за замовчуванням):** `https://strim.in.ua/…` — файли в `www/`
- **English:** `https://strim.in.ua/en/…` — файли в `www/en/`
- **Без Google Translate** — окремі HTML-сторінки, hreflang, перемикач мови веде на інший URL

**PL, DE, ES, FR** — окремі каталоги `www/pl/`, `www/de/`, `www/es/`, `www/fr/` (як EN).

Перегенерація перекладів з EN:

```bash
python3 run/i18n_build_locales.py
python3 run/i18n_faq_blog_translate.py
```

## Файли

| Файл | Призначення |
|------|-------------|
| `www/assets/i18n/locales.json` | Мапа маршрутів UK ↔ EN |
| `www/assets/js/strim-lang-switch.js` | Перемикач + hreflang |
| `www/en/` | Англійські сторінки |

## Додати переклад сторінки

1. Скопіювати `www/page.html` → `www/en/page.html`
2. Перекласти текст, meta, canonical (`https://strim.in.ua/en/page.html`)
3. Оновити посилання в nav на `/en/…`
4. Додати пару в `locales.json` → `routes`
5. `php run/generate_sitemap.php` — додати URL у sitemap
6. Деплой: `bash run/deploy_www_dashboard.sh`

## Кабінет

`dashboard.php` / SaaS UI — поки українською. Публічний маркетинг і блог — UK + EN.

## Російська

Окрема модалка «не підтримуємо» (без перекладу сайту).
