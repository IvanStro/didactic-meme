# ПриватБанк: три шляхи інтеграції та обмін з державою

Довідник для ТОВ «СтрІМ Алго» — що означають **Модуль обміну**, **Автоклієнт (.exe)** і **API**, і що з цього реально використовувати в StrIM.

---

## 1. Три різні інструменти (не плутати!)

У кабінеті **Приват24 для бізнесу → Облік та звіти → Інтеграція (Автоклієнт)** є три окремі підключення:

| Інструмент | Файл / формат | Де працює | Для кого |
|------------|---------------|-----------|----------|
| **Модуль обміну** | `.epf` / `.ert` (зовнішня обробка 1С) | Всередині **1С / BAS** | Бухгалтерія на 1С 8.2–8.3 |
| **Автоклієнт** | `.exe` + папки `balance\`, `statements\`, `prepared\` | **Windows-ПК** бухгалтера | Офлайн-обмін файлами DBF/CSV |
| **API** | HTTPS `acp.privatbank.ua` | **Будь-який сервер** (PHP StrIM) | Власні системи, SaaS, cron |

Офіційна сторінка: [privatbank.ua/business/intehratsiya](https://privatbank.ua/business/intehratsiya)

## 2. Модуль обміну (ваші перші 2 скріни)

### Що це
Зовнішня обробка для **1С:Підприємство / BAS** (версії 8.2–8.3 керовані або звичайні форми).  
Файл `privat24to8managed_*.exe` — інсталятор; робочий модуль — `.epf`/`.ert`, який відкривається в 1С.

### Можливості (за банком = як у API Автоклієнта)
- Виписки, платежі, залишки
- Електронний документообіг
- **Електронна звітність** (імпорт/реєстрація XML з 1С)
- Інтеграція з **Paperless**
- Зарплатний проєкт

### Інструкції
- Завантаження: кабінет → Модуль обміну → «Інструкція» біля кожної версії
- Сторонній гайд по документообігу + звітності: [softup.com.ua — модуль обміну 1С](https://softup.com.ua/modul-obmena-1c-privat-24-ukr/)
- Відео: посилання «Детальніше – у відеоінструкції» на [сторінці інтеграції](https://privatbank.ua/business/intehratsiya)

### Для StrIM
**Не підходить напряму** — StrIM не 1С. Має сенс лише якщо бухгалтер веде облік у 1С/BAS, а StrIM лишається реєстром доходів SaaS.

## 3. Автоклієнт .exe (ваші скріни 3–4)

### Що це
Windows-агент, який кожні N хвилин (у вас 15) синхронізує банк ↔ локальні папки:

| Папка | Призначення |
|-------|-------------|
| `balance\` | Залишки |
| `statements\` | Виписки (DBF/CSV) |
| `prepared\` | Платежі на імпорт у банк |
| `saved\` | Успішно імпортовані |
| `rejected\` | Відхилені |

Формат: **DBF**, кодування **cp1251** (як на скріні).

### Як працює
1. Встановити `.exe` на ПК (SHA256 у кабінеті).
2. Програма качає/віддає файли в папки.
3. Бухгалтерська програма читає DBF/CSV з диска.

### Обмеження
- Потрібен **постійно увімкнений Windows-ПК** (не Linux-сервер StrIM).
- Банк у попередженні прямо радить **API** замість застарілого файлового обміну.
- **Не дає** прямого HTTP для StrIM на `bot20`.

### Для StrIM
**Не рекомендується** для прод-сервера. StrIM вже використовує **API** (те саме джерело даних, без .exe).

## 4. API Автоклієнта (те, що вже є в StrIM)

### Що підключено зараз

- Cron: `run/privat_poll_transactions.php` → `bank_incoming_payments` → автопродовження підписки

## 5. Повний обмін з державними органами через ПриватБанк

### A. Електронна звітність (ДПС, Держстат) — головний канал

**UI (без програмування):**
- Меню: **Облік та звіти → Електронна звітність**
- Календар строків, створення форм, підпис **КЕП / SmartID**, надсилання в ДПС, квитанції
- Безкоштовно для клієнтів Приват24 для бізнесу

Офіційно:
- [Електронна звітність](https://privatbank.ua/business/elektronnyje-otchety)
- [Сервіси обліку та звітності](https://privatbank.ua/business/vse-servisy-ucheta-i-otchetnosti)
- [Довідник — календар звітності](https://privatbank.ua/handbook/elektronna_zvitnist_dlya_biznesu)

**Перед першим звітом:** Електронна звітність → **Налаштування** → коди ДПС/ПФУ, **згода на обмін з ДПС** (для автопідтягування оборотів з рахунків).

**API (для автоматизації):**
```
POST /api/proxy/eo/documents/create       — XML звітності (multipart)
POST /api/proxy/eo/documents/create-b64    — те саме в Base64
```
Параметри: `file` (XML за стандартом ДПС), `okpo` (ЄДРПОУ), `duplicate=error|remove`.

**Важливо:** API **завантажує** XML у кабінет Приват24. **Підпис КЕП і фінальна відправка в ДПС** — у веб/мобільному Приват24 (або через ключі SmartID). Повністю «без участі людини» неможливо без КЕП на сервері.

### B. Електронний документообіг (ЕДО)

Для **первинки між контрагентами** і **податкових накладних** (ЄРПН):

| Endpoint | Дія |
|----------|-----|
| `/api/proxy/edoc/loader/upload` | XML без підпису |
| `/api/proxy/edoc/loader/upload-signed-xml` | XML з ЕЦП |
| `/api/proxy/edoc/journal/inbox` | Вхідні |
| `/api/proxy/edoc/journal/outbox` | Вихідні |
| `/api/proxy/edoc/journal/get-xml-document/{id}` | Отримати XML |

Деталі — розділ 5 у [Autoclient API doc](https://docs.google.com/document/d/e/2PACX-1vTtKvGa3P4E-lDqLg3bHRF6Wi9S7GIjSMFEFxII5qQZBGxuTXs25hQNiUU1hMZQhOyx6BNvIZ1bVKSr/pub).

### C. Paperless
Окремий сервіс підписання/обміну між бізнесами. Інтегрується з модулем обміну 1С.  
[privatbank.ua — Paperless](https://privatbank.ua/business/intehratsiya) (розділ онлайн-сервісів).

### D. Прямо в ДПС (без ПриватБанку)
- [cabinet.tax.gov.ua](https://cabinet.tax.gov.ua) — електронний кабінет
- M.E.Doc, «Вчасно», СОТА — альтернативні провайдери ЕЦП/звітності
